# Hermes iOS 用户指南

适用于 v4。按一次实际使用的顺序组织：连接服务器，开始讨论并整理知识，再查找和复用内容，最后备份或处理服务端工作。

## 1. 连接自己的 Hermes 服务器

1. 在服务主机启用 Hermes Agent API Server，并准备手机可访问的服务地址与 API 密钥。主机上的 `127.0.0.1` 不能作为手机访问该主机的地址。
2. 打开“设置”，添加连接，填写名称、服务地址、密钥及本机聊天模型。服务根路径、`/v1` 和 Profile 路径均可使用。
3. 选择“读取模型列表”查看服务端公开的名称或别名，也可手动填写；模型列表不等于全部供应商模型。测试后检查名称并保存，实际模型由服务端配置决定。
4. 点击连接名称切换工作区。连接各自拥有本机对话、项目、资料、模板与草稿；生成回复期间先停止或等待完成，再切换或编辑连接。

修改名称、密钥或模型会保留对应本机内容；改用不同服务器地址时另存为独立连接。删除连接需确认，会删除该连接的本机记录、草稿、图片和钥匙串密钥，服务器会话与任务由服务器保留。

## 2. 开始对话并积累项目知识

### 先从工作台继续

工作台是首屏，提供新对话、继续草稿、最近对话、最近项目和统一检索入口。“全部对话”保留原有进行中、置顶、归档与回收站视图，支持标题/消息搜索、标签、排序和批量整理。

本机聊天支持流式回复、工具状态、停止和失败后重试。可选择一张图片，压缩后发送；图片理解由当前模型支持。Markdown 回复中的代码块可横向阅读并复制。

每段对话独立保存文字草稿与模型、供应商、系统提示词、上下文轮数。修改新对话的设置会成为当前连接之后新对话的默认值，不影响已有对话。尚未发送的图片不属于文字草稿，切换对话后需重新选择。

### 将长期讨论放入项目

1. 在“项目”创建名称、简介和共同指令。也可将既有对话单条或批量归入项目；解散项目会保留对话，解除项目关联。
2. 在资料库编写资料，或导入 UTF-8 的 Markdown/纯文本。单篇标题最多 80 字符、正文最多 20,000 字符；每项目最多 20 篇、正文合计 200,000 字符。
3. 为本机对话明确选择参考资料，按上下箭头调整顺序。每段最多 5 篇、50,000 正文字符；未选择的资料不会因为位于同一项目而自动发送。
4. 发送前打开“上下文预览”，检查本次模型、历史、系统指令、资料全文及图片数量，再返回聊天页手动发送。草稿或选择变化后重新预览。

项目共同指令、对话额外指令和所选资料共同进入实际请求。历史裁剪为 0 时发送完整本机历史，1–50 时保留对应轮次并包含本次问题；裁剪不会删除本机记录。上下文预览不提供令牌数量估算。

### 整理引用与聊天成果

- 资料可搜索、编辑、导出，或批量复制到同连接其他项目。资料详情可检查当前引用与关联对话；统计包含进行中、归档和回收站，不能据此推断过去是否发送过。
- 在资料库“整理资料”中可批量导出、复制或删除资料，以及添加/移除对话引用；单份资料详情继续提供替换引用。
- 批量添加引用将尚未引用的资料追加到末尾；批量移除保留其余项的相对顺序；替换引用后按首次出现位置去重。三种操作先检查每段对话的前后顺序和容量，确认后一次保存，不改写历史回复中的文字或编号。
- 相关资料、对话状态或引用发生变化时，旧检查会停止，返回重新检查。未选对话不会被纳入本次范围。删除资料前可检查影响，确认后解除相关选择并保留聊天内容。
- 单条项目消息可“存为项目资料”；跨多条消息的采集从“消息库 → 多选 → 更多 → 存为项目资料”进入。明确选择目标项目，编辑完整预填文字后新增一篇资料，不自动添加对话引用或发送。
- 多消息采集初始排除收藏备注，图片保留占位。预填最多 100,000 字符，超过 20,000 的全文可保留供精简，满足资料容量后才能保存。来源变化需回到消息库重新选择；只有目标项目变化时可明确重新检查目标并保留编辑输入。

资料编辑或采集页的未保存文字只留在当前页面，关闭后不自动恢复。需要保留输入时使用复制功能。项目资料保存和引用整理在生成回复期间需先停止或等待完成。

## 3. 统一检索并继续文字草稿

### 一次查找当前连接

1. 从工作台打开“统一检索”，输入关键词；空关键词不会返回全部内容。
2. 按类别查看项目、资料、对话、消息和本机文字草稿。每类最多展示 50 条，可看到该类别的匹配总数。
3. 需要查找旧内容时明确打开“包含归档”。默认排除归档；回收站、其他连接、服务端记录和远端会话草稿始终不在统一检索内。
4. 点击项目、资料、对话或消息，打开对应详情；点击草稿返回所属本机对话。打开前会核对当前连接及记录是否仍存在，内容删除或连接切换后需重新查找。

| 类别 | 匹配文字 |
| --- | --- |
| 项目 | 名称、简介 |
| 资料 | 标题、正文 |
| 对话 | 标题、标签 |
| 消息 | 正文、收藏备注 |
| 本机草稿 | 保存的文字草稿 |

匹配使用完整文字，列表摘要只是摘录，较长内容不会因摘要截取而失去匹配。检索在设备上完成，不向服务器发送关键词；打开结果也不会自动发送消息。

### 从“继续草稿”返回工作

工作台展示最多 3 条“继续草稿”，点击“全部草稿”可查看完整列表。新对话草稿优先，其余按关联对话的更新时间排列。草稿没有独立修改时间，此顺序不表示最近编辑顺序。

点开草稿后继续编辑并手动发送；打开新对话草稿不会提前创建聊天记录。已归档草稿可在包含归档的范围中找到，仍需恢复对应对话后才能发送。回收站草稿随记录保留，需要先从“全部对话 → 回收站”恢复。

### 将文字带入下一段讨论

- 提示词模板支持内置示例、自建模板、变量填写和全文预览。默认追加到草稿；替换非空草稿需再次确认，套用不自动发送。
- 从消息库多选后进入“引用到草稿”，核对当前目标对话或新对话草稿、完整引用和最终草稿。引用默认追加，替换非空草稿需确认；完整引用与最终草稿最多 100,000 字符，超限停止而不截断。
- 引用保留消息正文与来源，收藏备注排除，图片只保留占位。来源、目标或原草稿变化后旧检查不能保存，返回重新选择；可复制已生成的预览保存文字。

## 4. 收藏、查找和批量整理消息

“消息库”默认显示收藏，切换“全部”后可跨当前连接的本机对话查找。可组合项目、角色、标签和进行中/归档范围，始终排除回收站。单条详情可回到原文、复制文字、编辑收藏备注或分享。

1. 长按消息收藏，或打开收藏项添加最多 2,000 字符的备注。收藏与备注不会改变原对话的更新时间。
2. 点击“多选”，逐条选择或加入当前搜索结果。筛选隐藏的已选消息仍计入操作范围，页面显示隐藏数量；切换连接会清空选择。
3. 每次最多 100 条消息；正文、完整收藏备注及来源标题、项目名称、标签合计最多 500,000 字符。备注即使不进入导出或引用，仍计入来源容量。
4. 选择下列操作，先检查内容与影响后再确认。

| 操作 | 结果 |
| --- | --- |
| 导出 | 按消息创建时间从新到旧生成完整 Markdown，来源元数据作单行转义，正文保留原文；可预览、复制或导出文件。 |
| 引用到草稿 | 将来源与正文预览后追加或确认替换目标草稿，随后手动发送。 |
| 更多 → 存为项目资料 | 选择同连接项目，把多条消息编辑为一篇资料。来源可跨项目、未分组和归档。 |
| 更多 → 收藏/取消收藏 | 先检查实际变更数量；取消收藏会同时移除对应备注，需最终确认，原消息与图片保留。 |

Markdown 汇编默认不含收藏备注，需明确开启后才加入；图片不嵌入文件。汇编最多 1,000,000 字符，超限停止。它适合阅读与分享，完整结构和附件需使用 JSON 备份迁移。

## 5. 备份、迁移与恢复

1. 打开“设置 → 备份与恢复”，选择“导出备份到文件”。JSON 包含全部连接的本机数据；选择文件位置后保存。
2. 导入时选择已有 JSON，先检查备份时间、连接、项目、资料、对话、图片等数量及预计新增内容，确认后才合并。
3. 已存在的对话及非空草稿优先保留；重复导入同一份文件不会重复创建记录。新导入连接需要重新填写 API 密钥。

| 包含 | 不包含 |
| --- | --- |
| 连接名称、地址、模型与默认设置；项目、资料和引用；本机对话、回收站、已发送图片、草稿、收藏备注、自建模板、标签与归档状态 | API 密钥；服务器上的会话与任务；尚未发送的图片 |

v4 沿用 v1–v7 格式，按实际内容选择最低所需版本。含项目资料或引用时使用 v7，需 v3.0.0 或更新版本读取。备份最多 64 MB、100 个连接、5,000 段本机对话、100,000 条消息；文件含正文内容，保存到信任的位置。

备份不会持续同步设备。导入中断后，下次启动会尝试完成已开始的恢复。本机文件无法读取时，确认恢复会先保存原文件副本，再用备份恢复；不要把数据恢复界面的提示当作已成功完成。

普通删除先将对话移入回收站，恢复后保留草稿和收藏。彻底删除需确认，会移除对应草稿，仅在没有其他对话继续引用时清理图片。清理重要内容前可先导出备份。

## 6. 处理服务端会话和定时任务

### 远端会话

“服务端”读取 Hermes 服务器保存的记录，与本机对话独立，不会自动合并。可新建会话、搜索已加载记录、置顶、重命名、删除或分享文字；先加载最近 100 条消息，可继续读取更早记录。

续聊只提交新的文本，由服务端管理模型与上下文。工具需要审批时，可选择“允许本次”或“拒绝”；停止会向服务器请求中断，实际完成时间取决于正在运行的工具。连接中断后先刷新记录确认状态，App 不会自动重发。

服务端文字草稿仍按连接与会话保存在本机，可在原服务端会话中继续；它们不进入 v4 的统一检索或工作台本机草稿列表。

### 定时任务

可按名称、说明、日程或 ID 搜索，按运行中、需关注及已暂停筛选；详情可查看说明、运行时间、结果与错误。创建、编辑、暂停、恢复、删除或立即运行会改变服务端状态，按界面检查并确认。

日程使用服务端时区，例如 `every 1h`、`every day at 9am` 或 `0 9 * * *`。立即运行也会恢复暂停任务；“已接受运行”不等于已经执行完成，之后刷新结果。

任务列表支持手动或前台定时刷新；进入详情、切换页面或进入后台即暂停自动刷新，读取失败时逐步放慢并保留已有内容。复制为新任务只预填名称、说明和日程，检查后创建，不复制旧运行结果或自动运行。

## 验证边界

v4 的完整 475 项 XCTest 分别在 Mac Catalyst 与 iOS 18.1 通过，均为 0 失败、0 跳过且结果包无 runtimeWarnings；iOS Release 4.0.0 构建通过，三张隔离布局已逐张检查。详见 [v4 验证记录](VALIDATION-v4.0.0.md)。本轮尚未完成原生点击、真机、真实 Hermes API 端到端或系统文件往返验收；本项目交付 Xcode 源码预览，不含签名 IPA。

草稿自动保存出现错误时，请先保留当前输入并检查设备存储。切换本机对话、新对话或连接会先尝试保存，失败则停留当前目标；不要依赖退出 App 恢复尚未写入的文字。
