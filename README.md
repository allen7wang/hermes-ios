# Hermes iOS

一个原生 SwiftUI 客户端，用 iPhone 或 iPad 连接你自己的 Hermes Agent API Server。

当前版本为 **v3.9.0 · 多消息采集为项目资料**，仍以 Xcode 源码预览版交付。完整变更见 [CHANGELOG](CHANGELOG.md)，本次验证范围见 [v3.9 验证记录](docs/VALIDATION-v3.9.0.md)。

## 已实现

- 多消息采集为项目资料：从消息库多选，明确选择同连接目标项目，检查并精简完整汇编后新增一篇资料；保存前核对来源与目标，保留草稿及历史，不自动添加对话引用或发送。
- 多消息引用到草稿：从消息库多选，检查完整引用与目标草稿后追加，或确认替换非空草稿；来源、目标和原草稿变化时拒绝旧检查，保存后可查看目标草稿，不自动发送。
- 批量添加资料引用：选择资料顺序与目标对话，检查添加前后方案；保留原有位置，去重追加，超限或方案过期时整批停止。
- 消息库批量整理：多选当前连接的本机消息，检查后原子收藏或取消收藏；完整 Markdown 汇编支持预览、导出与复制，备注由用户明确开启，图片保留占位说明。
- 资料引用替换：选择同项目新资料和需要更新的对话，检查替换前后顺序及字符量，再一次保存；范围含归档与回收站，超限或过期方案整批拒绝。
- 资料引用检查：按已引用/未引用筛选、按标题或引用数量排序，查看包含归档与回收站的引用对话；单篇与批量删除前检查影响，过期确认会被拒绝。
- 资料批量整理：搜索多选、检查后汇编导出 Markdown、复制到其他项目，以及确认后批量删除；复制检查容量，删除同步解除相关引用。
- 聊天成果采集：从项目对话或消息库预填资料编辑器，检查后保存；可调整引用顺序，资料编辑和引用保存均检查窗口间的更新冲突。
- 项目知识库：编写或导入 UTF-8 Markdown/纯文本，搜索、编辑、导出资料；每段对话明确选择参考资料，预览全文后发送，随备份迁移。
- 项目工作区：项目简介与共同指令、独立对话草稿、单条/批量归属整理、项目进度与 Markdown 导出；按连接保存，随 JSON 备份迁移。
- 五个常驻入口：对话工作台、项目、服务端、消息库、设置；聊天页集中显示标题、当前模型和上下文范围。
- 本机对话支持标签、归档/恢复、置顶筛选、排序和批量整理；单段或多段记录可导出为 Markdown 文件。
- 删除本机对话先移入回收站，可撤销或批量恢复；草稿、图片和收藏保留到彻底删除。
- 发送前可预览实际将携带的本机历史、系统提示词、模型和图片数量；预览不发送请求。
- 每段本机对话独立保存模型、供应商、系统提示词和上下文轮数；也可为当前连接保存新对话的默认设置。
- 服务端任务显示运行中、需关注、已暂停概览，支持复制为新任务；可选择前台自动刷新并在读取失败时逐步放慢。
- 保存、编辑和切换多个服务器连接；各连接的密钥分别存于系统钥匙串，本机历史与文字草稿分别保存。
- 通过 `/v1/models` 读取可用模型名称或别名，支持列表选择及手动填写；测试连接，并在主界面查看当前连接名称与状态。
- 本机对话和服务端会话的文字草稿自动保存在设备上，切换会话或重新打开 App 后恢复；发送后清空对应草稿。
- 通过 `/v1/chat/completions` 实时显示流式回复与工具运行状态，支持停止和失败后重试。
- 从照片图库选择一张图片随消息发送；图片会压缩到最长边 1600 像素、最多 2 MB。
- 提示词模板用于本机聊天和服务端续聊，包含 5 个内置示例；支持自建、编辑、置顶、搜索及从草稿创建，填写变量后预览，再追加或确认替换草稿。
- 在当前本机对话或已加载的服务端消息中查找正文，点按结果定位并标记原消息；阅读历史时可暂停跟随回复，再一键返回最新。
- 本机消息库跨当前连接的全部本机对话查找正文、标题与收藏备注，支持收藏/全部及消息角色筛选，回到原文或引用到当前草稿。
- 收藏本机文字或图片消息，添加最多 2,000 字符的备注，查看完整内容、复制及分享文字；收藏和备注随备份保存。
- Hermes 回复按完整 Markdown 渲染(标题、列表、表格、引用、链接、行内代码);围栏代码块独立展示,带语法高亮、横向滚动和复制代码;长按消息可复制原文或分享文字。
- 从本机历史消息创建独立分支，或修改旧问题后在新分支重发，保留原对话、图片与文字草稿。
- 在设备本地保存对话和图片，支持置顶、搜索、查看消息摘要、重命名、分享文本、新建及删除对话；API 密钥存于系统钥匙串。
- 导出包含本机聊天图片的 JSON 备份，预览后合并导入；重复导入不产生重复记录，连接密钥不会进入备份。
- 在“服务端”新建和续聊远端会话，实时显示回复与工具进度；支持停止，以及服务端要求审批时的“允许本次”或“拒绝”。
- 查看远端会话，按标题、摘要、来源或 ID 搜索已加载的记录；支持服务端置顶和置顶筛选，以及重命名、删除、分享和分批读取更早的消息。
- 查看所有定时任务（包括已暂停任务），搜索名称、说明、日程或 ID，按状态筛选；详情页显示完整说明、运行时间、最近结果和错误，支持创建、编辑、删除、暂停、恢复或手动运行。
- 服务端读取失败时显示重试入口；刷新失败保留已有记录与上次成功刷新时间。

## 运行

1. 用 Xcode 打开 `Hermes.xcodeproj`，选择 `Hermes` scheme 和模拟器或真机。
2. 真机运行时，在 Xcode 的 Signing & Capabilities 中选择你的 Team，并按需修改 Bundle Identifier。
3. 在运行 Hermes Agent 的主机上启用 API Server：在 `~/.hermes/.env` 设置 `API_SERVER_ENABLED=true` 和 `API_SERVER_KEY=<your-secret>`，然后运行 `hermes gateway`。服务默认仅监听 `127.0.0.1:8642`；这是主机自身的回环地址，iPhone 无法直接连接。请为手机提供可访问的 HTTPS 地址，或在可信局域网中配置服务监听地址。
4. 在 App 的“连接管理”中编辑默认连接，或添加多个连接，填写可从手机访问的地址和密钥。地址可以是服务根路径、以 `/v1` 结尾，或包含服务端 Profile 路径，例如 `https://example.com/p/work/v1`。

远程服务要求 HTTPS。局域网 HTTP 只接受 `localhost`、`.local` 主机名及私有 IPv4 地址。不要把带有终端工具权限的 Hermes API 直接暴露到公网。

本仓库发布的是 Xcode 源代码工程，不包含签名后的 IPA。图片理解能力取决于你配置的 Hermes 模型。分享对话时导出文本，图片用 `[图片]` 标记；彻底删除本机对话时只清理其他对话（包括回收站）没有继续引用的本地图片。

“对话记录”保存于当前设备；“服务端”读取 Hermes 服务器上的会话，二者不会自动合并。服务端会话首次加载最近 100 条消息，可以继续加载更早的记录。续聊只发送新消息，由服务端管理上下文和模型；当前支持文本输入。若连接中断，请刷新记录确认服务端状态，App 不会自动重发消息。停止操作会向服务端请求中断，实际停止时间取决于正在运行的工具。

定时任务使用 Hermes 的日程表达式，例如 `every 1h`、`every day at 9am` 或 `0 9 * * *`，时间以服务端配置的时区为准。暂停、恢复及手动运行会直接改变服务器上的任务状态；立即运行也会恢复已暂停的任务。编辑只提交发生变化的名称、任务说明和日程，其他设置由服务器保留。删除任务会取消正在运行的任务，并需在 App 中确认。

## v3.9 多消息采集为项目资料

### 选择来源与目标项目

- 在“消息库”点击“多选”，选择消息后从底栏“更多”进入“存为项目资料”；原有批量收藏与取消收藏也在“更多”菜单中，“引用到草稿”和“导出”继续保留。
- 来源限当前连接的本机进行中与归档消息，可以跨项目，也可以包含未分组对话；不包含回收站、其他连接或服务端会话。搜索隐藏的已选消息仍计入范围，沿用每次最多 100 条、所选正文、完整收藏备注及来源元数据合计最多 500,000 字符的选择限制。
- 项目选择页显示当前连接各项目的资料篇数与容量，初始不选择任何目标。明确选择任一同连接项目后，才能准备编辑；目标可以与来源不同，也无需改变来源对话的项目归属。
- 至少一条所选消息需包含非空正文。初始正文使用完整消息汇编，保留来源对话、角色、时间、项目、标签、状态和正文，按消息时间从新到旧稳定排序；初始排除收藏备注，图片只保留未包含附件的占位说明，不读取或迁移原图。

### 检查完整预填与保存容量

- 编辑页预填资料标题与完整汇编正文，显示目标项目、来源范围、字符量和项目剩余容量，可在保存前修改标题、精简正文。预填汇编最多 **100,000 字符**；超限明确拒绝，不静默截取。超过 20,000、未超过 100,000 字符的正文仍完整保留在编辑器中，供手动精简，满足资料限制后才能保存。
- 最终资料标题为 1–80 字符且不能换行，正文为 1–20,000 字符；保存后目标项目最多 20 篇、全部正文合计最多 200,000 字符。按现有资料格式去掉标题与正文首尾空白，保留内部文字、换行和 Markdown，不截断内部内容。任一上限不满足或项目容量不足时不保存。
- 保存只在目标项目新增一篇资料，不覆盖已有资料，不自动为任何对话添加引用，也不发送请求。原消息、收藏、图片、历史顺序、现有草稿和对话归属保持；需要使用新资料时，再明确为相应对话选择引用。
- 保存成功后可点击“查看新资料”进入刚创建的资料详情。消息回复生成期间，项目资料保存会停用，需先停止或等待完成；失败不显示已保存结果。

### 冲突检查与未保存输入

- 保存前重新核对来源连接名称、所选消息与来源元数据的完整快照，以及目标项目的完整快照。所选来源正文、收藏、标题、归属或归档状态变化、来源缺失，或目标项目发生变化时，旧检查停止保存，需要重新检查；不自动使用更新后的来源覆盖编辑正文。
- 只有目标项目变化、来源仍与原快照一致时，可明确点击“重新检查目标”，刷新目标项目与容量，并保留当前标题和正文。来源已变化时不能仅刷新目标，需返回消息库重新选择。检查仅覆盖共享同一 AppModel 的窗口，不提供跨进程或跨设备锁。
- 可复制当前输入，保留自行编辑的标题与正文。未保存文字只保留在当前采集页，关闭页面或切换连接后不会自动恢复；取消不会创建资料或修改聊天草稿。
- 本版无新增持久化结构、API 或依赖。保存的资料沿用现有资料模型，含资料的 JSON 备份使用 v7，兼容读取 v1–v7；不含相关内容时仍按最低所需格式导出。

## v3.8 批量移除资料引用

在项目资料库点击“批量移除对话引用”，或从资料详情、批量整理页进入。选择需要解除引用的资料，再明确选择同项目目标对话；初始不选择任何对话，支持标题搜索、选择当前结果与隐藏选择提示。

- 可选择项目全部 20 篇、200,000 正文字符的资料库；实际只解除所选对话中已有的引用。进行中、归档和回收站均可明确纳入，未引用所选资料的对话显示无需改动；整批无需改动时不保存。
- 检查页展示完整移除前后顺序、编号、篇数和字符量，以及全部涉及资料的当前全文。其余资料保持相对顺序，后续请求按新顺序重新编号；原资料、历史消息中的旧编号与正文保留。
- 确认时重新检查资料快照、对话标题、所属项目、状态与完整引用。任一处改变或保存失败则整批停止，一次原子保存成功后才更新界面；无关资料、最新收藏、固定状态、草稿和未选对话的变更会保留。
- 与批量添加、替换引用及多消息引用到草稿共同使用。移除后可重新添加，追加到保留项后；如需调整编号，在对话设置中整理引用顺序。操作不发送请求、不恢复归档或回收站，生成期间需先停止或等待完成。
- 沿用 v1–v7 JSON 备份，按内容使用最低所需格式，无新增字段、依赖或 API。冲突检查限共享同一 AppModel 的窗口。

## v3.7 多消息引用到草稿

### 在消息库准备下一段讨论

- 在“消息库”点击“多选”，沿用搜索、角色、项目、标签和对话范围筛选，选择消息后点击底栏“引用到草稿”。底栏同时保留“导出”，批量收藏与取消收藏收进“收藏”菜单。
- 来源只包含当前连接的本机进行中及归档消息，不含回收站、其他连接或服务端会话。搜索或筛选隐藏的已选消息仍纳入操作，并显示隐藏数量。
- 目标是打开检查页时当前选中的本机进行中对话，或当前连接的“新对话”草稿。检查页明确显示目标名称、项目和原草稿字符数；目标已归档时需先恢复或选择其他目标。写入新对话草稿不会提前创建聊天记录。
- 引用复用消息汇编的来源信息与完整正文，逐行添加 Markdown 引用标记；按消息创建时间从新到旧排列，同时间按完整来源标识稳定排序，不重新排序来源对话。收藏备注始终排除，图片只保留未包含附件的占位说明，不加入待发送图片。

### 检查完整引用与最终草稿

- 检查页可展开查看完整引用、打开时的原草稿及最终整份草稿。默认“追加到草稿”，保留原文字并空一行后追加；也可切换“替换草稿”，用完整引用替换，原草稿非空时需再次确认。
- 继续沿用 v3.5 的选择范围：最多 100 条消息，正文、完整收藏备注及来源标题、项目名称和标签合计最多 500,000 字符。备注虽不进入引用，仍计入来源选择容量。
- **完整引用和最终草稿均最多 100,000 字符**，包含来源信息、换行和引用标记。超限明确拒绝，需减少消息、精简原草稿或在适用时选择替换，不静默截取。替换可以丢弃超长旧草稿，但新的完整引用仍须满足上限。
- 点击“复制预览草稿”可复制当前模式的最终文字；复制不会写入聊天草稿或发送。检查后发生冲突时，仍可复制已生成的旧预览，但保存必须返回重新检查，不能自动覆盖新输入。

### 保存前核对与返回目标

- 提交时重新核对来源连接名称、全部所选消息及其来源元数据、目标对话和项目，以及目标草稿键和原草稿全文。来源正文、收藏、标题、状态、归属变化，目标切换、归档或草稿变化时，旧检查整批拒绝；确认替换时也会再次核对。

- 保存成功后显示“引用已保存到目标草稿”，点击“查看目标草稿”返回目标聊天；不会跳到任一来源消息。若目标已切换或归档，跳转入口停用，可从对话记录打开目标。确认保存前取消或返回，不会写入草稿。
- 本版无新增持久化结构、API 或依赖；引用作为普通文字保存于现有草稿。完整 JSON 备份继续按内容选择最低所需格式，兼容读取 v1–v7。

- 只更新后续请求使用的资料选择，一次原子保存成功后更新界面；不改变草稿、图片、日期、归档或回收站状态，不自动发送，也不改写历史文字与编号。需要调整时可在对话的“参考资料”页重新选择，重要内容也可先备份。
- 无新增数据字段、接口或依赖，继续兼容 v1–v7 JSON 备份。共享同一 AppModel 的窗口适用，不提供跨进程或跨设备锁。

- 变更一次原子保存成功后才更新界面，不部分显示成功；无需变更的批次不写入文件。可在生成期间整理既有消息，保持对话顺序、消息、当前聊天与草稿，不自动发送请求。
- 没有新增持久化字段、API 或依赖。完整 JSON 备份继续按内容选择最低所需格式，兼容读取 v1–v7；只有收藏信息时沿用现有 v2 格式，已有项目资料时继续使用 v7。

- 当前已打开的发送预览在引用变化后需要重新检查。替换仅影响后续请求，历史消息里的文字、引用编号与曾发送的内容不会重写；需要恢复选择时可重新选择资料或使用备份。
- 没有新增持久化字段、接口或依赖，继续使用现有 v7 资料备份并兼容读取 v1–v7。并发检查限共享同一 AppModel 的窗口，不提供跨进程或跨设备锁。

- 引用统计和检查都是本机派生信息，无新增持久化字段；继续兼容 v1–v7 JSON 备份。存储需要恢复时，引用统计不可用，清理操作停止。并发检查限共享同一 AppModel 的窗口，不提供跨进程或跨设备锁。

## v3.0 项目知识库

### 保存项目资料

- 在项目详情打开“项目资料库”，可以编写资料，或从“文件”App 导入 UTF-8 `.txt` / `.md` 文件。支持带 BOM 的 UTF-8；每次最多读取 256 KiB，其他编码、空内容和二进制内容会被拒绝。导入先打开编辑器，检查并保存后才加入项目。

### 明确选择本次参考内容

- 打开一段已有的项目对话，点按“参考资料”选择并保存。每段对话最多选择 5 份，正文合计最多 50,000 字符；选择顺序对应请求中的 `[资料1]`、`[资料2]` 等编号。未选择的资料不会自动发送。
- 发送顺序为项目指令、对话指令、所选资料全文，然后是按上下文轮数整理的消息。项目简介、其他对话和未选择资料都不会自动带入。资料选择、修改或删除后，已打开的上下文预览会提示重新检查。
- 所选资料用于这段对话之后的每次本机发送及重试；更改选择后，后续请求使用新的选择。分支继承选择，移动到不同项目时清空选择，同项目整理保持选择。归档对话可调整选择，恢复后发送生效；回收站记录需先恢复。
- 资料超过上限会明确拒绝，不会静默裁剪。编辑资料若让已有对话（含回收站）的选择合计超过 50,000 字符，也会拒绝保存。字符数量不是模型令牌容量；服务端的上下文容量与引用标注质量仍取决于所用模型。

### 删除、导出与备份

- 删除资料需确认，会解除本项目所有对话（包括归档和回收站）的相应引用，保留聊天、草稿、图片和其他资料。解散项目会同时删除项目资料库并清空相关引用，保留原对话。已发给服务端的内容不会因此撤回。
- 对话及项目的 Markdown 导出不附带资料原文；单份资料可独立导出 Markdown。完整迁移请使用 JSON 备份。
- 含资料或引用的备份使用 **v7**，需要 v3.0.0 或更新版本读取；本版可读 v1–v7。没有资料时继续按内容使用最低所需版本。
- 备份包含项目全部资料（包括未选择的资料）及每段对话的选择。跨安装导入稳定映射资料标识，重复导入补充缺失资料，保留本机已有资料编辑和对话选择。删除资料后再导入旧备份可能补回定义，但不会恢复已有对话中已移除的选择。

## v2.0 项目工作区

### 把相关对话放在一起

- “项目”页可创建、搜索、编辑项目，查看进行中、已归档和回收站数量，打开原对话或在项目内开始新对话。每个连接最多 100 个项目，名称 1–60 字符，简介最多 2,000 字符。
- “在项目中新建对话”会先保存一段空记录，打开它自己的草稿；不会发送请求，也不会把原对话或通用新对话的草稿搬过来。第一次发送后自动生成标题。未发送的空记录也会计入项目对话数量。
- 工作台可查看全部项目、未分配对话或指定项目，并与归档、回收站、标签和排序组合筛选。单条或批量整理可移动到项目，也可移回未分配；对话设置中的项目归属与其他设置一起保存。
- 同一段对话只属于一个项目；分支继承来源项目。移入回收站保留归属，恢复后仍回到原项目。回收站记录需先恢复后才能更改归属。

### 共同指令，明确预览

- 项目简介只用于本机说明目标，不会自动发送。项目共同指令最多 8,000 字符，每次本机项目对话请求会先带入项目指令，再带入该对话自身最多 10,000 字符的额外指令；项目不会自动读取其他对话的历史。
- 聊天栏显示所属项目及共同指令状态。“上下文预览”显示项目来源和本次合成后的完整系统指令；项目修改、归属或草稿变化后，旧预览会提示重新检查。实际发送仍以发送时的内容为准。
- 项目仅组织本机对话，不创建服务端项目，也不修改服务端续聊或定时任务。请求中的指令与模型最终如何执行，取决于 Hermes 服务端；项目本身不提供跨设备同步。

### 解散、导出与迁移

- 解散项目需确认，只删除项目定义并解除当前连接所有相关对话（含归档和回收站）的归属，保留消息、图片、收藏、标签、配置、日期与各段草稿。保存失败不显示成功；多文件写入使用恢复日志。
- 项目 Markdown 导出只包含进行中和已归档的对话、标签及图片占位说明，不包含图片文件、项目简介、共同指令、收藏备注或回收站。完整迁移请用 JSON 备份。
- 仅含项目及归属时使用备份 **v6**，需 v2.0.0 或更新版本导入；兼容读取 v1–v7，含资料时提升到 v7；没有项目时按内容导出最低所需格式。备份包含项目简介和共同指令。
- 重复导入只补充缺失项目与记录，保留已有项目编辑及对话归属；跨设备导入会重新映射项目与对话关联。解散项目后再导入含该项目的旧备份可能补回项目定义，但不会重新关联已存在的本机对话。

## v1.1 回收站与上下文预览

- 工作台新增“回收站”。普通删除会移入回收站，当前页面可撤销，也可在回收站查看原消息、单段或批量恢复。记录不会自动过期；恢复保留原来的归档、置顶、标签、模型设置、收藏备注、草稿、图片和更新时间。
- 移入回收站的记录不会出现在普通工作台、消息库或发送上下文中。删除当前对话后回到新对话；恢复原记录再打开，可继续自己的草稿。回收站只读，恢复后才能继续使用。
- “彻底删除”仅在回收站中提供，需确认；会清理该记录和对应草稿，图片仅在所有记录都不再引用时清理。删除与彻底删除使用恢复日志，中断后下次启动继续完成；保存失败时不会显示已成功。
- 本机聊天输入区新增“上下文预览”，显示当前连接、请求模型、供应商、裁剪后的历史消息、未带入条数、图片数量和额外系统指令。与实际请求共用上下文整理逻辑，不包含收藏备注，也不提供令牌数量估算。
- 预览不联网、不发送、不保存尚未发送的图片；返回编辑后手动发送。草稿、对话或设置改变会提示重新预览，实际发送以当时的内容为准。预览与发送都会修剪输入首尾空白，单次输入最多 100,000 字符。服务端会话仍由服务器管理上下文，不使用此入口。
- 消息库右上角筛选菜单可组合“全部 / 进行中 / 已归档”、对话标签及 Hermes/我角色；文字搜索也匹配标签。结果显示标签和归档状态，始终排除回收站。
- 含回收站记录的备份使用 **v5**，需 v1.1.0 或更新版本读取；导入后仍在回收站。当前兼容 v1–v7，含项目时提升到 v6；其余情况按内容选择较低格式。重复导入保留已有记录及其本机恢复或整理结果。备份包含回收站里的聊天内容与图片，彻底删除前仍可从新备份恢复。

## 对话工作台

- 打开 App 后进入工作台。顶部统计可切换“进行中 / 已置顶 / 已归档 / 回收站”；按标签筛选，搜索标题、消息或标签，并按最近更新、最早更新或标题排序。工作台、消息库及连接数据都按当前连接隔离。
- 长按一段记录打开“对话设置与标签”，可改名并添加最多 8 个标签，每个最多 20 字符；中文或英文逗号分隔，重复标签会合并。整理与归档不改变消息时间和最近更新时间。
- 归档保留原消息、图片、收藏和草稿，并从进行中移出。已归档对话可以阅读、查找和创建分支，恢复后才能继续发送。分支继承标签与对话设置，自动回到进行中，不重复原消息的收藏。
- 工作台右上角菜单进入“批量整理”，点选记录或选择当前结果，再归档/恢复、导出或移入回收站；回收站中可批量恢复或确认彻底删除。改变筛选后只保留仍可见的选择。
- 聊天页顶部的设置栏可调整当前对话。模型留空时使用连接模型；具体模型是否生效取决于服务端路由，指定供应商时需同时填写模型。系统提示词作为额外指令随每次请求发送，最多 10,000 字符，不替代 Hermes 核心指令。
- 上下文为 0 时发送完整本机历史，1–50 时只发送最近相应轮次（**包含本次问题**），每轮从用户问题开始。裁剪不删除本机内容，不会读取已排除历史的图片，也不清除服务器记忆。服务端会话继续由服务器管理上下文，不使用这些本机对话设置。
- 在新对话中修改设置，会作为当前连接之后新对话的默认值保存；修改默认值不改变已有对话。修改连接名称、密钥、模型保留默认值，更换服务器地址产生独立连接和默认值。
- “导出 Markdown”通过系统文件导出器保存 `.md`，可单段导出或将所选记录合并为一个文件。包含标题、标签、消息原文及图片占位说明，不包含图片文件、收藏备注、系统提示词、服务器地址或 API 密钥；完整迁移仍使用 JSON 备份。
- 含标签、归档、对话设置或新对话默认设置的备份至少使用 **v4**，需 v1.0.0 或更新版本读取；含回收站记录提升到 v5。未使用新字段时继续导出内容所需的较低版本。重复导入保留已有对话及其本机修改，新导入连接携带自己的默认设置，密钥仍需重新填写。

## 服务端任务增强

- 定时任务列表新增运行中、需关注、已暂停统计，点按可筛选；“需关注”可以与已暂停重叠，因为最近一次运行失败不表示任务仍在运行。
- 右上角时钟菜单可选择手动刷新或每 30 / 60 / 120 秒刷新。默认手动；仅在任务列表可见且 App 位于前台时读取，进入任务详情、编辑/创建任务、切换页面或进入后台即暂停。失败后指数放慢，最长间隔 300 秒；成功后回到所选间隔。手动下拉刷新始终可用，失败保留原记录与上次成功时间。
- 任务详情的“复制为新任务”预填名称、说明和日程，检查并点按创建后才提交；不自动运行，也不复制任务 ID、运行结果、错误或投递设置。一次性任务清空旧时间，必须重新填写日程。其他未填写设置由服务器使用默认值。

## 提示词模板

- 本机聊天和服务端会话的输入框上方均有“提示词模板”入口。内置会议纪要、代码检查、写作润色、学习讲解和任务拆解 5 个示例；长按示例可复制为自己的模板。
- 右上角“＋”可新建模板，或使用当前文字草稿创建。自建模板按连接保存，长按可编辑、置顶或确认删除；支持按名称和正文搜索，以及“全部 / 我的模板”筛选。修改连接名称、密钥或模型会保留模板，更换服务器地址创建的新连接拥有独立模板。
- 正文中的 `{{主题}}` 是变量，可使用中文、英文、数字和下划线，名称最多 40 字符；重复变量只填写一次。双大括号为变量专用，必须成对。每个连接最多保存 100 个模板，名称最多 60 字符，正文最多 10,000 字符，最多 20 个不同变量。
- 填写变量后显示完整文字预览，每个值最多 10,000 字符，套用后的提示词最多 50,000 字符。变量值作为原文插入，其中的大括号不会再次被解释；未填写、格式错误或超出限制时不能套用。
- 默认追加到当前草稿；选择替换且草稿非空时需再次确认。套用不会切换对话或自动发送，保存失败时保留原草稿；草稿总长度最多 100,000 字符。模板只包含文字，当前已选择的图片保持不变。
- 模板及置顶状态随备份恢复。含自建模板的备份至少使用格式 v3，需 v0.10.0 或更新版本导入；含工作台新字段至少使用 v4，需 v1.0.0 或更新版本。含回收站记录至少使用 v5，含项目时使用 v6；本版本可读取 v1–v7。重复导入保留本机已编辑模板，仅补充缺失模板。
- 变量填写值不保存为模板默认值，仅在套用后进入对应草稿。删除模板保留已套用的草稿文字；删除连接会删除该连接的自建模板。模板不上传或同步到服务器，发送后服务端会收到草稿中的文字。

## 本机消息库与收藏

- 聊天右上角“⋯ → 本机消息库”汇总当前连接的所有本机消息，默认查看收藏。切换“全部”可跨对话搜索文字正文、对话标题或收藏备注；右上角可按 Hermes/我筛选，结果显示来源对话和匹配位置附近的内容。搜索在设备上完成，输入时短暂等待合并连续按键，较早的查找结果不会覆盖新条件。
- 长按本机聊天消息可收藏或取消收藏，已收藏的消息可添加备注。消息库详情显示完整文字与本机图片，可编辑备注、复制原文或分享文字与备注。收藏按收藏时间排序，全部消息按消息时间排序；收藏和编辑备注不会改变对话的更新时间。
- 消息库详情的“回到原文”打开所属对话并定位到该条消息，同时恢复该对话自己的文字草稿；当前对话的草稿仍会保留。回复进行中仍可查找、收藏和引用，回到原文需先停止或等待回复完成。
- “引用到当前草稿”追加带来源标题和角色的引用文字，不会自动切换对话或发送请求，也不附带图片或收藏备注。单次引用最多取正文前 4,000 字符，过长时明确标记截取；草稿加引用最多 100,000 字符。可返回聊天补充问题后再发送。
- 收藏属于原消息。移入回收站后暂时隐藏，恢复对话后重新显示；彻底删除原对话或删除连接会移除其中的收藏。创建分支会保留原收藏，新分支不重复收藏。各连接的消息库独立；目前不收藏或统一检索服务端会话，不进行图片 OCR。
- 收藏及备注会随本机备份恢复。含收藏的备份至少使用格式 v2，需 Hermes iOS v0.9.0 或更新版本导入；使用模板或工作台新字段时提升到相应版本。重复导入优先保留设备上已有对话及其收藏备注。

## 消息查找、代码与分支

- 本机聊天右上角“⋯ → 查找消息”搜索当前对话的完整文字正文；点按结果回到原消息并标记“定位消息”。搜索支持中文、大小写及重音字符匹配，摘要显示匹配位置附近的内容。
- 服务端会话右上角“⋯ → 查找已加载消息”仅搜索当前已加载且可见的消息正文。更早的消息需先返回会话、加载历史，再查找；此功能不调用服务器全文搜索，也不识别图片中文字。会话列表的搜索仍只匹配列表摘要。
- Hermes 回复中的反引号或波浪号围栏代码块按原缩进和换行展示,长行可横向滚动;“复制”只复制代码内容,显示复制反馈。代码块带语法高亮(atom-one-dark 配色,覆盖 highlight.js 全部语言及 sh/py/js 等常见别名;未知语言、纯文本或超长代码自动回退纯单色显示)。回复正文按完整 Markdown 渲染:标题、有序/无序列表、带边框和隔行底色的表格、左侧竖线引用块、下划线链接与行内代码;单个换行保留为换行。用户、工具和系统消息仍按原文字展示。
- 长按本机消息，选择“从这里创建分支”，会复制截至这条消息的上下文，原对话保留；创建本身不会发送请求。长按自己的问题，选择“修改后重新发送”，可编辑文字并选择是否保留原图片，点按“创建并发送”后创建新分支并请求回复。旧问题之后的消息不会进入新上下文。
- 分支使用当前连接和模型，保存在本机；不会修改或创建服务端工作区中的会话。原对话与分支拥有独立文字草稿，共享图片会在仍有引用时保留，并可随备份迁移。回复进行中需要先停止或等待完成才能创建分支。
- 上下拖动阅读或定位搜索结果时暂停自动跟随；点击“返回最新”回到底部并恢复跟随实时回复。服务端加载更早消息时也会保持阅读位置。

## 服务端查找与任务详情

- 会话列表搜索只匹配当前已加载记录的标题、摘要、来源和 ID；完整消息正文可进入会话后查找。页面显示已加载数量；每次继续读取 50 段会话，即使当前没有匹配结果也可加载更多。
- 服务端会话向右滑动或长按可置顶、取消置顶，置顶记录优先显示。置顶保存在服务器上，可与其他支持该字段的客户端共享；服务端未返回 `pinned` 字段时不显示置顶入口。
- 会话与任务分别保留自己的搜索条件。任务可筛选“计划中、运行中、已暂停、需关注、已完成”；“需关注”包含错误状态、最近错误和最近运行或投递失败，不等同于任务已停止。
- 点击任务打开详情，进入时读取最新定义；可复制完整说明和错误文本，也可手动刷新。带时区的运行时间转换为设备本地时间，缺少时区或无法解析的时间保留原文；日程表达式的执行时区仍由服务端决定。
- “立即运行”只表示服务端已接受调度请求，结果需后续刷新查看。如果请求已提交但刷新失败，页面会明确提示，避免误以为操作失败而重复运行。
- 切换服务器连接会建立独立的工作区；较早的刷新响应不会覆盖较新的结果。会话分页会去除重复记录，并保留服务端回补的置顶会话。

## 多连接、模型与草稿

- 点击连接列表中的名称切换当前连接，点击铅笔编辑；保存后该连接成为当前连接。回复进行中需要先停止或等待完成才能修改连接。
- 升级时，旧服务地址、模型、钥匙串密钥和本机历史自动归入“默认连接”。修改名称、密钥或模型会保留该连接的记录；改用不同的服务器地址会另存为新连接，原连接和记录仍可切换回来。末尾 `/v1`、默认端口等写法差异不会创建新连接。
- 左滑删除连接需要确认，会删除对应的全部本机历史（包括回收站）、图片、文字草稿和密钥；不会删除服务器上的会话或任务。
- “读取模型列表”读取 `/v1/models` 公布的名称或别名；列表不代表所有供应商模型。测试连接不会自动替换手动填写的名称，选好模型后需要保存。实际模型由 Hermes 服务端配置决定，服务端会话继续使用自己的模型设置。
- 文字草稿按连接、会话分别保存，仅存在当前设备，不跨设备同步。新对话也有独立草稿。尚未发送的图片不属于草稿，切换对话时会清除，需要重新选择。

## 备份与恢复

在“连接管理 → 备份与恢复”中将备份导出到“文件”App，或选择已有的 Hermes JSON 备份。导入前会显示备份时间、记录数量与预计新增内容，确认后才会写入设备。

- 备份包含所有连接的名称、地址、模型与新对话默认设置，以及项目、项目简介、共同指令、全部项目资料与对话引用选择、本机对话（包括回收站）、已发送图片、置顶、归档、标签、对话设置、草稿、收藏备注和自建提示词模板。不包含连接的 API 密钥，也不下载服务器上的会话或任务。
- 正常导入会合并新增记录；已存在的对话和非空草稿优先保留。重复导入同一份备份不会重复创建连接、对话或图片。新导入的连接标注“已导入”，使用前需要重新填写密钥。
- 备份仅用于保存和迁移，不会持续同步设备。文件含有聊天内容，请自行保管；目前最多支持 64 MB、100 个连接、5,000 段本机对话和 100,000 条消息。
- 导入中断时，App 下次启动会尝试完成已开始的恢复。本机数据无法读取时，确认恢复会先保留原连接、对话和草稿文件的副本，再从备份恢复记录；副本位于 App 数据目录的 `Recovery` 文件夹。
- 在本机对话记录中向右滑动或长按可置顶、取消置顶。置顶对话显示在列表顶部，其他对话按最近更新时间排列，记录行会显示最近消息摘要。

## 构建

```sh
xcodebuild -project Hermes.xcodeproj -scheme Hermes \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

工程文件可用 `ruby tools/generate_project.rb` 重新生成。脚本只纳入文件名符合常规 Swift 标识符的源码,跳过带空格的同步副本,并自动写入 MarkdownUI 与 Highlightr 两个 Swift Package 依赖(首次构建需联网解析)。图标可用 `python3 tools/generate_icon.py Hermes/Assets.xcassets/AppIcon.appiconset/AppIcon.png` 重新生成。
